1. SCHEMA MIGRATIONS — four scripts written today
--------------------------------------------------------------------------------
   code/api/docs/migrations/

   2026-08-03-drop-upload-source-is-seeded.sql          (14:09)
     Drops lakeshore.upload_source.is_seeded. The flag made 'business card',
     'facebook' and 'linkedin' undeletable through the API; it had no teeth
     because no foreign key points at the table and UploadSourceModel.list
     unions the seeded rows with the values actually in use. Every entry is
     deletable now, with the per-entry use count as the guard rail.

   2026-08-03b-backfill-comparison-result-friend-names.sql   (14:28)
     PHASE 1 of 2, non-destructive. Moves comparison_result.friend_name into
     friend_name_en / friend_name_th, routing by script (Thai block U+0E00–U+0E7F
     → th, otherwise en) — the same rule the importer's routeFriendNames applies.
     Only ever fills a NULL, so a matcher-supplied spelling always wins. Reports
     the count of still-stranded rows via RAISE NOTICE so it can be eyeballed
     before anything is dropped.

   2026-08-03c-drop-comparison-result-friend-name.sql        (14:29)
     PHASE 2, irreversible. Drops comparison_result.friend_name, but ENFORCES the
     precondition rather than documenting it: raises and rolls back if any row
     would lose its only name. Documents what is lost (which spelling a run
     scored is now inferred from comparison.compare_by) and the one external
     breakage — the external matcher's direct INSERT names friend_name and will
     fail after this; the HTTP callback path is unaffected.

   2026-08-03d-comparison-sources.sql                        (15:59)
     comparison.source (varchar, never written by anything) → comparison.sources
     (text[]). Adds idx_friend_source ON friend (lower(source)) for the matcher's
     new WHERE clause. NULL means "every source", matching the selected_companies
     convention; guarded so it refuses the drop if any row does carry a value.
